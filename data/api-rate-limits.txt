Лимиты API

Публичный API ограничен 100 запросами в минуту на один API-ключ для бесплатного тарифа и 1000 запросами в минуту для тарифа Pro. При превышении лимита сервер возвращает статус 429 с заголовком Retry-After, в котором указано количество секунд до сброса лимита.

Внутренние сервисные токены (service tokens), используемые между нашими собственными микросервисами, не имеют лимита по количеству запросов, но ограничены по полосе пропускания — 50 МБ/с на токен.

Лимиты считаются по скользящему окну в 60 секунд (sliding window), а не по фиксированным минутным интервалам — это сделано, чтобы клиент не мог обойти лимит, отправив 100 запросов в последнюю секунду одной минуты и ещё 100 в первую секунду следующей.

Увеличение лимита для конкретного клиента можно запросить через форму в личном кабинете; заявки рассматриваются в течение 2 рабочих дней.
